# Optional dependencies for local Live2D / 2D Puppet layer decomposition (See-through).
# Keep these inside an isolated virtual environment (recommended: ~/.pebblecompanion/inochi2d-venv,
# so both source runs and packaged builds share one environment cleanly).
#
# Quick setup (Python 3.11 / 3.12 recommended):
#   1) Create & activate the isolated venv:
#      - Windows:
#          python -m venv "%USERPROFILE%\.pebblecompanion\inochi2d-venv"
#          "%USERPROFILE%\.pebblecompanion\inochi2d-venv\Scripts\activate.bat"
#      - Linux / macOS (Experimental - untested):
#          python3 -m venv ~/.pebblecompanion/inochi2d-venv
#          source ~/.pebblecompanion/inochi2d-venv/bin/activate
#
#   2) Install PyTorch first for YOUR hardware (do NOT install CPU-only torch unless testing):
#      - NVIDIA GPU (CUDA 12.x, Windows / Linux):
#          pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126
#      - AMD GPU (ROCm on Linux, Experimental):
#          pip install torch torchvision --index-url https://download.pytorch.org/whl/rocm6.3
#      - AMD GPU (ROCm on Windows):
#          install AMD's matching Windows ROCm PyTorch wheels per your Adrenalin/ROCm driver release
#      - macOS Apple Silicon MPS (Experimental - untested) / CPU fallback:
#          pip install torch torchvision
#
#   3) Install the headless inference & post-processing stack:
#        pip install -r backend/Inochi2D/requirements.txt
#      (On macOS/Linux, ensure Xcode Command Line Tools / build-essential is installed if pycocotools needs building.
#       In Windows packaged builds, this file is also copied to %USERPROFILE%\.pebblecompanion\inochi2d-requirements.txt.)
#
#   4) Download the two HuggingFace model repositories into your configured modelsRoot:
#      - seethroughv0.0.2_layerdiff3d   (https://huggingface.co/layerdifforg/seethroughv0.0.2_layerdiff3d)
#      - seethroughv0.0.1_marigold      (https://huggingface.co/24yearsold/seethroughv0.0.1_marigold ; also accepts folder name seethroughv0.0.1_marigol)
